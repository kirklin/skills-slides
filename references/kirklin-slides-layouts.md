# 版式目录

版式定义一页包含的内容以及内容的排列结构，与风格无关。`assets/pages/` 中每种版式有一页样例，所有风格共用。样例的文件名由序号和版式英文名组成，例如 `05-tiles.html`。某种风格需要不同的结构时，在 `assets/styles/<风格>/pages/` 中放置同名页面，替换共用的样例。

新建页面时，先用 `add-page.ts` 复制样例，再修改文字和数据，详细步骤参见 [`kirklin-slides-workflow.md`](kirklin-slides-workflow.md)。

全部版式及其适用内容如下表：

| 版式 | 英文名 | 适用内容 |
|-|-|-|
| 封面 | cover | 项目名、副标题、团队和日期 |
| 目录 | agenda | 三到六个部分的列表 |
| 章节页 | section | 新部分的开始 |
| 要点 | bullets | 三到六条并列的结论或事项 |
| 大数字 | hero | 一个关键数字和两到三个补充事实 |
| 数字方块 | tiles | 三到六个数字，每个数字对应一件事 |
| 对比 | compare | 两种做法的取舍 |
| 四象限 | matrix | 按两个维度分组的事项 |
| 表格 | table | 多个事项在多个方面的比较 |
| 横条 | bars | 多个对象的数值比较，或新旧两次数值的对比 |
| 柱状图 | columns | 一组时间段的数值 |
| 折线图 | line | 一到两个指标随时间的变化 |
| 环形图 | donut | 一个总数的构成 |
| 漏斗 | funnel | 逐级减少的多个阶段 |
| 时间轴 | timeline | 多个里程碑和当前进度 |
| 路线图 | roadmap | 多个阶段及各阶段的事项 |
| 甘特图 | gantt | 按周排期的任务 |
| 双轨 | tracks | 同时进行、时长不同的两件事 |
| 流程 | process | 三到六个先后进行的步骤 |
| 引述 | quote | 一段原话和说话人 |
| 图文 | image-text | 一张图片和图片说明 |
| 图标列表 | features | 三到六个特点或能力 |
| 团队 | team | 成员、角色和分工 |
| 截图 | posts | 社交媒体帖子或网页截图 |
| 标志墙 | logos | 合作方、客户等标志 |
| 代码 | code | 一段关键代码和说明 |
| 结束页 | closing | 结束语和联系方式 |

## 通用规则

- 先确定页面标题，再根据页面的主要内容，按上表选择版式。
- 每页只使用一种版式，内容超出一页时拆分为多页。
- 网格类版式（要点、数字方块、路线图、图标列表、团队、截图、标志墙）根据项数通过 `--cols` 调整列数，避免最后一行只有一项。参数说明参见 [`kirklin-slides-components.md`](kirklin-slides-components.md) 中的「版式参数」。
- 样例中的占位文字全部替换为用户的内容，用户未提供的部分整块删除。检查脚本会报告未替换的占位文字。
- 所需的版式不在本目录中时，先在本目录中补充该版式的适用内容和排版规则，再将英文名加入 `scripts/lib/constants.ts` 的 `LAYOUTS`，在 `assets/pages/` 中按顺序补充样例页，并为每种风格补充样式。测试会检查样例页与 `LAYOUTS` 是否一一对应。

## 封面 cover

封面包含项目名、副标题、团队名和日期。项目名保持用户提供的写法，大小写和空格不做修改；项目名和副标题不加句号。副标题、团队名和日期根据需要添加，用户未提供时删除。

## 目录 agenda

目录列出三到六个部分，每项包含序号、部分名称和一句说明。部分名称与后续章节页的名称一致。

## 章节页 section

章节页包含大号序号、部分名称和一句说明，序号与目录一致。

## 要点 bullets

要点页列出三到六条，每条包含一个短标题和一句说明。每条前的图标表示该条的性质：满足条件使用对勾，需要注意使用感叹号，补充信息使用信息图标。

## 大数字 hero

大数字页展示一个数字和单位，下方一行说明数字的含义，标题和正文解释这个数字的意义。页面底部可以补充两到三个事实，每个事实为一个短数字或名称，附一到两行说明。

## 数字方块 tiles

数字方块页包含三到六个并列的方块，每个方块自上而下为标签、数字和单位、说明文字。标签用于解释数字的含义，说明文字最多两行。

数字和单位保持在同一行，空间不足时缩短单位。说明文字的最后一行只有一两个字时，删减文字使其缩为一行，或补足为完整的两行。

## 对比 compare

对比页包含两张并排的卡片，左侧为未选用的做法，右侧为选用的做法，选用的卡片需要有明显的标记。两侧的行数相同，同一行对应同一个方面，每行包含一个短标题和一句说明。未选用的一侧使用感叹号图标，选用的一侧使用对勾图标。

## 四象限 matrix

四象限页先说明两个坐标轴的含义，四个格子分别包含名称、一句做法和所属的事项。优先处理的格子使用重点标记。

## 表格 table

表格只包含需要比较的列，第一列为事项名称，数字列靠右。状态使用标签表示，重点行使用底色标出。超过六行时拆分为两页，或只保留重要的行。

## 横条 bars

横条每行包含四列，依次为名称、说明规模或时长的数字、横条和数值。材料中只有一种数量时，第二列使用能说明规模的数字；没有这类数字时，删除第二列。

同一份文档中单位相同、需要相互比较的横条和柱状图使用同一个比例尺。比例尺按其中的最大数值确定，并在页脚注明。甘特图和时间轴按各自的时间范围绘制，不与横条共用比例尺。

横条的宽度为数值除以比例尺上限得到的百分比，保留两位小数。数值为区间时，横条分为两段：实色部分画到下限，半透明部分从下限画到上限。两段之间的间隙从后一段中扣除，横条的总长度仍等于上限。

新旧对比时每行包含两条横条，新数据在上，旧数据在下，图例注明两种颜色的含义。

## 柱状图 columns

每根柱子对应一个时间段，柱子上方标注数值，下方标注时间。需要强调的柱子使用第一种数据颜色，其余柱子使用灰色。柱子的高度为数值换算出的百分比，最高的柱子为 85%，上方留出标注数值的空间。

## 折线图 line

每页最多两条折线，终点绘制圆点并标注最新的变化。横轴的时间点均匀分布，第一个和最后一个时间点分别位于图表的左右两端。折线坐标写在 SVG 中，横向范围为 0 到 100，纵向范围为 0（最高）到 100（最低）。

## 环形图 donut

环形图一般不超过五类，按占比从大到小排列，占比较小的几类合并为「其他」。圆环中间标注总数或 100%，右侧列出每一类的颜色、占比、名称和说明。每一段使用 SVG 圆的 `stroke-dasharray` 绘制，段与段之间留出 1 个百分点的间隙。

## 漏斗 funnel

漏斗的每一层对应一个阶段，宽度为该层数值占第一层数值的比例。左侧标注阶段名称，右侧标注该层相对上一层的转化率。标题说明流失最多的环节。

## 时间轴 timeline

时间轴包含四到六个里程碑，每个里程碑包含日期、名称和一句说明。已完成、进行中和未开始的里程碑需要明显区分，已完成的部分用强调色的线连接。

## 路线图 roadmap

路线图的每一列对应一个阶段，包含阶段名称、时间和该阶段要完成的事项。进行中的阶段使用强调色标出。

## 甘特图 gantt

甘特图左侧一列为名称和起止时间，右侧为时间轴，顶部为图例和里程碑名称，底部为刻度。

起止时间根据材料中的时长和先后顺序计算，计算方法在页脚注明。材料中只有时长、无法确定具体周次时，左侧标注时长，不绘制刻度。

材料中的时长为范围（例如 3 到 4 周）时，实色部分画到下限，下限到上限之间使用余量的浅色，图例注明「估算的上限」。后续任务按上限排期，左侧标注「最晚第 X 到 Y 周」，页脚注明「按估算的上限排」。

「余量」仅用于计划中专门预留的时间。条形上标注时长，例如「6 周」；余量、观察期等时间段标注名称。首尾相接的两段之间保留间隙，间隙从后一段中扣除；后面紧接余量的一段添加 `join` 类名。

里程碑用竖向虚线贯穿各行，名称位于虚线正上方。

步骤指每一行都要经过的环节，例如梳理、开发、测试、上线。材料中列出这类步骤时，在刻度下方增加一行步骤。回退期、观察期等时间段绘制在条形上，不属于步骤。

行数较少时，通过 `--row` 增大行高，避免图表下方出现大面积空白。

## 双轨 tracks

双轨页包含两条轨道，上方为先完成的事项，下方为同时进行、持续时间更长的事项。两件事时长不同且没有共同的时间刻度时，不标注周数和日期，只表示先后和重叠关系。

顶部标注关键时间点的名称，并用竖向虚线标出，虚线只画到第二条轨道的上沿，不穿过文字。每条轨道下方附一到两行说明文字，介绍该轨道的具体内容。

## 流程 process

流程包含三到六个步骤，每个步骤包含序号、名称和一到两行说明，步骤之间用箭头连接。最关键的步骤使用重点标记。

## 引述 quote

引述页照录原话，最多三行，用直角引号括起。原话下方标注说话人的姓名和身份；没有照片时，头像显示姓氏。

## 图文 image-text

图文页左侧为眉标题、标题、正文和两到三条要点，右侧为图片。要点需要指明图中对应的位置。图片尚未提供时使用占位框，并注明图片的用途和宽高比。

## 图标列表 features

图标列表包含三到六项，每项包含一个图标、一个短标题和一句说明。图标仅表示类别，同一页中不重复使用。

## 团队 team

团队页的每位成员包含姓名、角色和负责的工作；没有照片时，头像显示姓氏。六人以内放在一页，人数较多时按小组拆分。两人或四人时使用 `--cols: 2`，其余情况使用默认的三列。

## 截图 posts

截图按网格排列，每个格子上方标注发帖人，下方为截图，超出格子的部分裁切并淡出。最后一格可以放置一张数字卡片，汇总这些截图说明的情况。页脚注明截图来源和时区。截图尚未提供时使用占位框，框内写图片路径。

## 标志墙 logos

标志放在大小相同的格子中，按统一的规则排列，例如合作开始的时间。标志尚未提供时使用占位框。

## 代码 code

代码页只展示关键的几行代码，左侧说明这几行代码的作用。代码块添加 `translate="no"`，每行不超过 70 个字符，超出时换行或删减。

## 结束页 closing

结束页包含一句结束语和一句副标题，结束语不加句号。联系方式和二维码根据需要添加，用户未提供时删除。
