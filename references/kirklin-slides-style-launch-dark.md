# 黑底发布会风格（launch-dark）

## 适用场景

黑底发布会风格使用纯黑背景、大号标题和彩色光晕，每页表达一个结论，适用于立项、方案汇报和投屏讲解。该风格每页的文字较少，以标题和大数字为主。需要大段文字或需要打印的材料不适合使用该风格。

## 文件

样式文件为 `assets/styles/launch-dark/style.css`，实现了 [`kirklin-slides-components.md`](kirklin-slides-components.md) 中的全部类名。该风格没有替换页面，样例使用 `assets/pages/` 中的共用页面。执行以下命令可生成该风格的样例汇总图：

```bash
node <skill 目录>/scripts/preview-style.ts launch-dark 汇总图.png
```

## 画布和边距

版心的左右边距各为 128，上边距为 112，下边距为 64，分别定义在四个 `--safe-*` 变量中。

页面采用纵向的弹性布局，标题区在上，页脚在下，`.content` 占满中间的空间。标题和正文各为一行时，内容区的纵向位置从 409 左右开始，到 964 左右结束。

内容区宽度为 1664。多栏布局使用 CSS grid，栏间距为 24 到 32。

## 颜色

颜色变量及用途如下表：

| 变量 | 值 | 用途 |
|-|-|-|
| `--bg` | `#000` | 整页纯黑的背景 |
| `--text` | `#f5f5f7` | 标题、大数字、强调的文字 |
| `--text-2` | `#86868b` | 正文、说明、图例 |
| `--text-3` | `#6e6e73` | 页脚、占位文字、步骤之间的箭头 |
| `--accent` | `#2997ff` | 眉标题、序号、选用的做法、我们自己 |
| `--card`、`--card-2` | `#1d1d1f`、`#2c2c2e` | 卡片底色，头像和图标的底色 |
| `--hairline` | `rgba(255, 255, 255, 0.12)` | 分隔线、刻度线、占位框 |
| `--guide` | `rgba(255, 255, 255, 0.35)` | 里程碑等竖向虚线 |
| `--critical` | `#ff453a` | 严重 |
| `--serious` | `#ff9f0a` | 警告、难点、需要审查 |
| `--warning` | `#ffe680` | 一般问题 |
| `--ok` | `#30d158` | 满足条件，只用于图标和标签 |
| `--low` | `#636366` | 原有的做法、对照的数据 |
| `--parallel` | `#64d2ff` | 与蓝色同时进行的第二件事 |
| `--wait` | `#48484a` | 观察期等等待的时间段 |

数据颜色依次为 `--series-1` 蓝色、`--series-2` 青色、`--series-3` 橙色和 `--series-4` 灰色。

同一页中，一种颜色只表示一种含义。正文和说明只使用三种灰白色，彩色只用于眉标题、序号、标签和图表。

## 字体和字号

各类文字的样式如下表：

| 用途 | 字号 | 字重 | 其他 |
|-|-|-|-|
| 眉标题 | 30 | 600 | `--accent` |
| 标题 | 96 | 600 | 行高 1.12，字距 -0.015em；每行最多 17 个字，最多两行 |
| 正文 | 32 | 400 | 行高 1.55，`--text-2`；`<b>` 为 600、`--text` |
| 页脚、页码 | 20 | 400 | `--text-3` |
| 卡片标题、要点标题 | 26 到 40 | 600 | |
| 卡片说明、图例、刻度 | 21 到 26 | 400 | `--text-2`，行高 1.45 到 1.55 |
| 方块中的大数字 | 64 | 600 | 单位为 28 |
| 大数字页的数字 | 420 | 600 | 单位为 120 |
| 封面项目名 | 168 | 700 | 从白色经蓝色到青色的横向渐变 |

字体使用系统界面字体，代码使用系统等宽字体，不加载网络字体。最小字号为 20，投屏时无法看清的说明直接删除，不缩小字号。

## 基调和光晕

每页包含一团径向渐变的光晕，绘制在 `.slide::before` 上。`.slide` 设置了 `isolation: isolate`，光晕位于内容下方、背景上方。

光晕颜色由 `data-tone` 决定：`accent` 为蓝色，`critical` 为红色，`serious` 为橙色，`parallel` 为青色，`none` 不显示光晕。

光晕默认位于右上方，大部分在画布之外。封面和结束页的光晕为覆盖整个画布的大椭圆，大数字页的光晕位于数字后方，章节页的光晕位于左侧。

数字方块的标签和团队的角色同样使用基调颜色。

## 组件样式

通用组件的样式如下表：

| 组件 | 样式 |
|-|-|
| 卡片 | 底色为 `--card`，圆角为 24 到 32。选用的卡片增加 2 像素的蓝色内描边。 |
| 标签 | 胶囊形，字号 18，字重 600。状态标签为浅色底和同色文字。 |
| 胶囊 | 1 像素的 `--hairline` 描边，字号 22。 |
| 状态图标 | 彩色圆形，内部为黑色的对勾、感叹号、叉或「i」。 |
| 类别图标 | 蓝色线条，放在 `--card-2` 的圆角方块中。 |
| 占位框 | 2 像素的 `--hairline` 虚线，圆角 16，框内文字为 `--text-3`。 |
| 图例 | 色块为 28×14、圆角 4，字号 22。 |
