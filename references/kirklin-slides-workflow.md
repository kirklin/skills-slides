# 制作流程

配图的创建、渲染、检查和导出均通过本 skill 的 TypeScript 脚本完成，脚本位于 `scripts/` 目录。下文中的 `<skill 目录>` 指本 skill 所在的目录，`<风格>` 指所选风格的英文名，例如 `launch-dark`。

## 环境准备

脚本需要 Node 22.18 及以上版本，并使用本机的 Chrome 渲染页面。首次使用前，执行以下命令安装依赖：

```bash
pnpm --dir <skill 目录> install
```

脚本默认使用的 Chrome 路径为 `/Applications/Google Chrome.app/Contents/MacOS/Google Chrome`。Chrome 安装在其他位置时，通过环境变量 `CHROME` 指定路径。

## 目录结构

配图位于项目的 `slides/` 目录中，目录结构如下表：

| 路径 | 说明 |
|-|-|
| `slides/style.css` | 所选风格的样式，第一行注明风格名。 |
| `slides/pages/NN-名称.html` | 每页一个文件，`NN` 为两位序号，与文档中的出现顺序一致。 |
| `slides/assets/` | 页面使用的图片，例如 `assets/posts/` 存放帖子截图。 |
| `slides/out/NN-名称.png` | 渲染结果，文档引用此处的 PNG。 |

一个项目只使用一种风格，项目中已有 `style.css` 时沿用该风格。文件名中的「名称」使用小写英文短词，根据页面内容命名，例如 `05-process`、`08-cost`。项目中的辅助脚本使用 TypeScript 编写，不使用 `.mjs` 和 `.js`。

## 创建配图目录

执行以下命令，将风格的 `style.css` 复制到 `slides/`，并创建 `slides/pages/`：

```bash
node <skill 目录>/scripts/use-style.ts <风格> slides
```

`slides/style.css` 已存在时，脚本报错并停止，不会覆盖已有文件。更换风格时，先将旧的 `style.css` 移到废纸篓，再执行一次该命令。所有页面使用相同的结构，更换风格后需要重新渲染、检查并查看图片。

skill 中的风格更新后，项目中的 `style.css` 不会随之更新。需要使用新增的参数或组件时，同样先移走旧的 `style.css`，再执行一次该命令。

## 添加页面

1. 确定眉标题、标题和正文，按 [`kirklin-slides-layouts.md`](kirklin-slides-layouts.md) 选择版式。
2. 复制该版式的样例。风格有同名页面时复制风格的页面，否则复制共用的样例。
   ```bash
   node <skill 目录>/scripts/add-page.ts slides <版式英文名> NN-名称
   ```
3. 修改文字和数据。数字、人名和日期的要求参见 [`kirklin-slides-copy.md`](kirklin-slides-copy.md) 中的「数据来源」，类名参见 [`kirklin-slides-components.md`](kirklin-slides-components.md)。
4. 渲染该页。
   ```bash
   node <skill 目录>/scripts/render.ts slides NN-名称
   ```
5. 用 Read 工具打开 `slides/out/NN-名称.png`，对照「常见版面问题」逐项检查。
6. 运行检查脚本。
   ```bash
   node <skill 目录>/scripts/check-pages.ts slides/pages
   ```
7. 在文档中插入图片，写法为 `![说明](slides/out/NN-名称.png)`。插入位置和图片说明的写法参见 [`kirklin-slides-copy.md`](kirklin-slides-copy.md) 中的「文档中的配图」。

## 渲染

```bash
node <skill 目录>/scripts/render.ts slides
node <skill 目录>/scripts/render.ts slides 05-process 08-cost
```

未指定页名时，脚本渲染 `slides/pages/` 中的全部页面；指定页名时，只渲染指定的页面。渲染结果为 3840×2160 的 PNG，输出到 `slides/out/`。

页面引用的样式表或图片加载失败时，脚本报错，不生成该页。脚本运行成功仅表示文件已生成，版面是否正确需要查看图片确认。

## 常见版面问题

查看渲染结果时，常见的问题和处理方式如下表：

| 问题 | 处理方式 |
|-|-|
| 渐变文字的下半部分被裁切 | 增大行高，或为文字增加下内边距。 |
| 网格中的一列被内容撑开，超出卡片 | 列宽设为 `1fr` 或固定像素值，文字容器添加 `min-width: 0`。 |
| 最后一行的分隔线紧贴卡片边缘 | 最后一行不添加下边线。 |
| 虚线穿过文字 | 为虚线设置固定高度，使其止于文字上方。 |
| 最后一行只有一两个字 | 删减几个字，或用 `<br>` 调整换行位置。 |
| 刻度文字超出版心 | 第一个刻度靠左，最后一个刻度靠右。 |
| 方块中的说明超过两行 | 缩短说明。 |
| 内容下方出现大面积空白 | 改用更合适的版式，或将内容拆分为两页。 |

## 检查文字和版面

```bash
node <skill 目录>/scripts/check-pages.ts slides/pages
node <skill 目录>/scripts/check-pages.ts slides/pages/05-process.html
```

检查脚本的检查项如下表：

| 检查项 | 说明 |
|-|-|
| 空格 | 中文与英文、数字之间缺少空格，或汉字之间有多余的空格。 |
| 标点 | 中文旁使用了半角标点，或全角标点旁有多余的空格。 |
| 数值范围 | 数值范围未使用「到」连接。 |
| 用词 | 使用了「而是」「落地」「钉死」「对齐」「赋能」「抓手」「闭环」「打通」「颗粒度」「底层逻辑」或「栈」（「全栈」除外）。 |
| 版心 | 文字超出版心。版心取自页面样式中的 `--safe-top`、`--safe-right`、`--safe-bottom`、`--safe-left`，样式中未定义这四个变量时，脚本报错。 |
| 容器 | 文字超出卡片，或被 `overflow: hidden` 的容器裁切。 |
| 线条 | 有颜色的细线（分隔线、虚线）穿过文字，被不透明背景遮挡的部分除外。 |
| 最后一行 | 一段文字的最后一行只有一个字。 |
| 图片 | 图片加载失败。 |
| 占位文字 | 样例的占位文字未替换。与样例页中四个字以上、不含数字的文字完全相同时，视为未替换。 |
| 占位框 | 页面中仍有占位框（`.ph`）。图片、标志和二维码需要替换为实际内容，用户未提供时删除该区域。 |
| 页面样式 | 页面中写了 `<style>`。版式调整只使用 [`kirklin-slides-components.md`](kirklin-slides-components.md) 中的「版式参数」。 |

发现问题时，脚本逐条列出页面、问题类型和对应的文字，退出码为 1。`translate="no"` 范围内的文字不检查空格和标点。检查脚本只检查文字和位置，颜色、留白和整体效果需要查看图片确认。

## 调整顺序和重新编号

配图的序号与文档中的顺序保持一致。插入或移动页面后，按以下步骤为后续页面重新编号：

1. 从序号最大的文件开始依次向后移动，全部移动完成后再放入新页面，避免覆盖尚未移动的文件。
2. 同时修改 `pages/` 和 `out/` 中的文件名，并逐一修改文档中的引用。
3. 运行导出脚本，确认文档引用的图片均存在，且序号与顺序一致。

## 导出全部配图

```bash
node <skill 目录>/scripts/export-slides.ts 文档.md 输出目录 [汇总图的标题]
```

脚本按文档中的出现顺序复制每张配图，文件名为 `序号 说明.png`；同一张图被多次引用时只导出一次。复制完成后，脚本生成 `汇总.png`，以最多三列的方式排列全部配图，每张图下方标注序号、说明和所在章节。汇总图的宽和高均不超过 16384 像素，图片较多时自动缩小。

汇总图的标题默认为「文档文件名的全部配图」。文件名无法体现材料名称时，通过第三个参数指定标题，格式为「材料名称的全部配图」。

输出目录必须为空。重新导出前，先将旧的输出目录移到废纸篓（`/usr/bin/trash 目录`）。

图片不存在、图片缺少说明，或配图序号与文档中的顺序不一致时，脚本报错，不生成任何文件。

用户要求导出「全部配图」时，导出整份文档的配图；只导出修改过的配图时，需要用户明确说明。

## 预览风格

```bash
node <skill 目录>/scripts/preview-style.ts <风格> 汇总图.png
```

脚本使用指定的风格渲染全部版式的样例，并生成一张汇总图；目标文件已存在时，脚本报错。用户需要了解或对比风格时，为每种风格各生成一张汇总图。

## 截取社交媒体帖子

1. 打开帖子并阅读全文，确认帖子内容与页面要表达的内容一致。
2. 执行截图命令。
   ```bash
   node <skill 目录>/scripts/post-shot.ts slides/assets/posts post-1=帖子链接 post-2=帖子链接
   ```
3. 用 Read 工具查看截图，确认内容完整、时间正确。
4. 将截图放入截图版式的格子中，并在格子上方标注发帖人。

脚本支持链接中包含 `/status/<编号>` 的帖子，也支持直接填写编号。截图使用帖子的官方嵌入组件，默认为深色主题、简体中文和北京时间，可通过环境变量 `POST_THEME`（`dark` 或 `light`，按风格规范选择）、`POST_LANG` 和 `POST_TZ` 调整。运行脚本的电脑需要能够访问该平台。
