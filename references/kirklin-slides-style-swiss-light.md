# 白底瑞士风格（swiss-light）

## 适用场景

白底瑞士风格使用白色背景、黑色的大号无衬线字体、网格和细线，强调色为红色，适用于方案汇报、数据较多的分析材料和需要打印的文档。该风格的页面按网格排列，以标题、数字和图表为主，标题、正文和图表均左对齐。在较暗的环境中投屏时，大面积的白底较为刺眼，宜使用黑底发布会风格。

## 文件

样式文件为 `assets/styles/swiss-light/style.css`，实现了 [`kirklin-slides-components.md`](kirklin-slides-components.md) 中的全部类名。该风格没有替换页面，样例使用 `assets/pages/` 中的共用页面。执行以下命令可生成该风格的样例汇总图：

```bash
node <skill 目录>/scripts/preview-style.ts swiss-light 汇总图.png
```

## 画布和边距

版心的左右边距各为 120，上边距为 96，下边距为 64，分别定义在四个 `--safe-*` 变量中。

版心宽度为 1680，按 12 栏的网格排列，每栏宽 118，栏间距 24。半页为 6 栏，宽 828；第 7 栏的左边缘位于 972。多栏版式的栏间距均为 24。

页面采用纵向的弹性布局，标题区在上，页脚在下，`.content` 占满中间的空间。标题和正文各为一行时，内容区的纵向位置从 415 开始；有页脚时到 951 结束，没有页脚时到 1016 结束。

## 颜色

颜色变量及用途如下表：

| 变量 | 值 | 用途 |
|-|-|-|
| `--bg` | `#fff` | 整页白色的背景 |
| `--text` | `#111` | 标题、正文、数字、图例和刻度 |
| `--text-2` | `#5c5c5c` | 说明文字、注释 |
| `--text-3` | `#8c8c8c` | 页脚、占位文字 |
| `--accent` | `#e30613` | 序号、选用的做法、我们自己、进度，以及默认基调的方块 |
| `--card`、`--card-2` | `#f2f2f2`、`#e4e4e4` | 重点行、代码块、汇总卡片和图片区的底色；头像和完成标签的底色 |
| `--rule` | `#111` | 眉标题上方、各栏顶部、表头下方的黑色线 |
| `--hairline` | `#d4d4d4` | 行与行之间的分隔线、刻度线、页脚上方的线 |
| `--guide` | `rgba(17, 17, 17, 0.55)` | 里程碑等竖向虚线 |
| `--critical` | `#111` | 严重，用于黑底白字的标签和黑色的叉号图标 |
| `--serious` | `#f08c00` | 警告、难点、需要审查 |
| `--warning` | `#ffd200` | 一般问题 |
| `--ok` | `#111` | 满足条件，用于对勾图标和完成标签的文字 |
| `--low` | `#c4c4c4` | 原有的做法、对照的数据、未开始的阶段 |
| `--parallel` | `#1d4fd8` | 与红色同时进行的第二件事 |
| `--wait` | `#e6e6e6` | 观察期等等待的时间段 |

数据颜色依次为 `--series-1` 红色、`--series-2` 黑色、`--series-3` 深灰色和 `--series-4` 浅灰色。

同一页中，一种颜色只表示一种含义。红色只用于基调色、序号、选用的做法、我们自己的数据、进度和代码的关键字；严重使用黑底白字的实心标记；正文和说明只使用黑色和两种灰色。

## 字体和字号

各类文字的样式如下表：

| 用途 | 字号 | 字重 | 其他 |
|-|-|-|-|
| 眉标题 | 22 | 700 | 字距 0.04em。上方为 2 像素的黑色线，文字前为 18×18 的基调色方块 |
| 标题 | 96 | 700 | 行高 1.1，字距 -0.01em；每行最多 17 个字，最多两行 |
| 正文 | 30 | 400 | 行高 1.5，`--text`；`<b>` 为 700 |
| 页脚 | 20 | 400 | `--text-3`，上方为 1 像素的 `--hairline` |
| 页码 | 20 | 700 | `--text` |
| 卡片标题、要点标题 | 26 到 44 | 700 | |
| 说明、图例、刻度 | 21 到 26 | 400 到 500 | 说明为 `--text-2`，行高 1.45 到 1.5；图例和刻度为 `--text` |
| 方块中的大数字 | 88 | 700 | 字距 -0.02em，单位为 32 |
| 大数字页的数字 | 400 | 700 | 字距 -0.05em，单位为 120 |
| 封面项目名、结束语 | 200 | 700 | 字距 -0.035em |

西文和数字使用 Helvetica Neue，中文使用系统黑体，代码使用系统等宽字体，不加载网络字体。页面关闭了合成粗体，中文的粗体使用系统黑体自带的最粗字重。最小字号为 20，投屏时无法看清的说明直接删除，不缩小字号。

## 基调和装饰

每页的眉标题上方为一条横跨版心的 2 像素黑色线，眉标题文字前为一个 18×18 的方块。方块颜色由 `data-tone` 决定：`accent` 为红色，`critical` 为黑色，`serious` 为橙色，`parallel` 为蓝色，`none` 不显示方块。

封面和结束页的整页背景为基调色，文字为白色；基调为 `serious` 时文字为黑色，基调为 `none` 时背景为白色、文字为黑色。

大数字页的数字上方为 14 像素高的基调色色条，章节页的序号、数字方块的标签和团队的角色同样使用基调色。
