# 页面结构和组件

所有风格共用同一套 HTML 结构和类名，样式由各风格的 `style.css` 定义。页面只包含结构和内容，由数据决定的长度和位置（例如横条宽度、甘特图的起止）以百分比写在 `style` 属性中，其余样式均由风格决定。同一页面更换风格时，只需替换 `style.css`。

## 页面结构

每一页的基本结构如下：

```html
<main class="slide tiles" data-tone="serious">
  <header class="head">
    <p class="eyebrow">眉标题</p>
    <h1 class="headline">一个写结论的句子。</h1>
    <p class="body">正文，一到两句话。</p>
  </header>
  <div class="content">版式自己的内容</div>
  <footer class="foot">资料来源或者计算方法</footer>
  <span class="page-no">03</span>
</main>
```

各部分的说明如下表：

| 类名 | 说明 |
|-|-|
| `.slide` | 整页。类名后接版式英文名，例如 `slide tiles`。 |
| `data-tone` | 页面的基调，风格据此确定装饰和标签的颜色。可选值为 `accent`（默认）、`critical`（严重）、`serious`（警告）、`parallel`（同时进行的第二件事）和 `none`（无装饰）。 |
| `.head` | 标题区，包含眉标题、标题和正文。 |
| `.eyebrow`、`.headline`、`.body` | 依次为眉标题、标题和正文。正文中需要强调的句子使用 `<b>`。 |
| `.content` | 版式内容，自动占满标题区和页脚之间的空间。 |
| `.foot` | 页脚，注明资料来源或计算方法，没有时省略。 |
| `.page-no` | 页码，位于右下角，按需添加。 |

封面、章节页、结束页和图文页不包含 `.head`，结构参见各自的样例。

## 通用组件

通用组件可用于任何版式，类名和用途如下表：

| 类名 | 样式 | 用途 |
|-|-|-|
| `.card` | 卡片底色和圆角 | 对比、四象限、方块 |
| `.card.pick` | 卡片加强调色描边 | 选用的做法、重点格子 |
| `.tag` | 实心小胶囊 | 「选用」「进行中」等标记 |
| `.tag.ok`、`.tag.warn`、`.tag.critical`、`.tag.muted` | 完成、警告、严重、未开始 | 表格中的状态 |
| `.pill` | 描边胶囊 | 步骤、事项 |
| `.big` 加 `<small>` | 大数字加单位 | 方块、截图汇总 |
| `.note` | 小一号的说明文字 | 方块和卡片中的说明 |
| `.ph` | 虚线占位框，框内写图片路径或用途 | 尚未提供的图片、标志、二维码、截图 |
| `.avatar` | 圆形头像，没有照片时显示姓氏 | 团队、引述 |
| `.legend` | 图例，写法为 `<span><i class="s1"></i>名称</span>` | 图表上方 |
| `.s1` 到 `.s4` | 第一到第四种数据颜色 | 横条、柱子、折线、环形图、图例 |
| `.spare`、`.wait` | 余量、等待的时间段 | 甘特图、双轨 |
| `.icon.ok`、`.icon.warn`、`.icon.no`、`.icon.info` | 对勾、感叹号、叉、信息 | 要点、对比 |
| `.icon.bolt`、`.icon.shield`、`.icon.clock`、`.icon.people`、`.icon.chart`、`.icon.doc` | 速度、安全、时间、协作、数据、文档 | 图标列表 |

## 图表类名

图表版式使用的类名如下表：

| 版式 | 类名说明 |
|-|-|
| 横条 | `.row` 为一行，`.name`、`.size`、`.value` 为三列文字。`.track` 中放置 `.bar.s1` 等横条，横条中第一段 `<i>` 为实色部分，`<i class="range">` 为浅色的区间部分。 |
| 柱状图 | `.plot` 中每根柱子为 `.col.s1`，`<b>` 为数值，`<i style="height: …">` 为柱子。`.axis` 为时间。 |
| 折线图 | `.plot` 中放置 SVG 的 `polyline.s1`，终点为 `.point.s1`，终点的数字为 `.label`。 |
| 环形图 | `.ring` 中放置 SVG 的 `circle.track` 和每一段 `circle.s1`，`.parts` 为右侧的说明。 |
| 甘特图 | `.marks` 为里程碑名称。`.rows` 中先放置 `.lines`（刻度线 `<i>` 和里程碑虚线 `i.milestone`），再放置各行 `.row`。行中的 `.label` 为名称，`.track` 中为 `.bar`。`.bar.join` 为后面紧接余量的一段，只有左侧为圆角；`.bar.spare` 为余量，`.bar.wait` 为等待的时间段。`.ticks` 为刻度，`.steps` 为步骤。 |
| 双轨 | `.marks` 为时间点名称，`.guides` 为竖向虚线，`.lane.first` 和 `.lane.second` 为两条轨道。轨道中包含 `.name`、`.track` 和 `.notes`。第二条轨道的阶段为 `.bar.p1` 到 `.bar.p4`，上线时间点为 `.dot`。 |
| 时间轴 | `<ol>` 中每个 `<li>` 为一个里程碑，`.done` 表示已完成，`.now` 表示进行中，没有类名表示未开始。`.date` 为日期，`.dot` 为圆点。 |
| 路线图 | 每个 `.phase` 为一个阶段，`.done` 表示已完成，`.now` 表示进行中。 |
| 分层结构 | 每个 `.layer` 为一层，`.layer.pick` 为最关键的一层，`.layer.down` 在每个模块下方显示向下的箭头。层中每个 `.group` 为一组，包含名称 `.name` 和模块列表 `.cells`。模块为 `<li>`，名称写在 `<b>` 中，说明写在 `<small>` 中，`li.more` 为表示省略的一格。 |

## 版式参数

页面通过 `.content` 上的以下变量调整版式，所有风格均需支持：

| 变量 | 说明 | 默认值 |
|-|-|-|
| `--cols` | 网格的列数，用于要点、数字方块、路线图、图标列表、团队、截图和标志墙。 | 要点为 2，路线图和标志墙为 4，其余为 3 |
| `--row` | 甘特图的行高。 | 由风格决定 |
| `--done` | 时间轴已完成部分的长度，写在 `<ol>` 上。 | 0% |
| `--span` | 分层结构中一组所占的份数，写在 `.group` 上。 | 1 |

例如，四人团队写作 `<ul class="content" style="--cols: 2">`。

## 编写规则

- 颜色、圆角和字号使用类名表示，页面中不写具体的颜色值。
- 由数据决定的长度和位置以百分比写在 `style` 属性中，例如 `<i style="width: 25%"></i>`。版式调整只使用「版式参数」中的变量。
- 页面中不写 `<style>`，检查脚本会报告该问题。本文件中没有所需的调整时，先在本文件中增加参数或类名，再在每种风格的 `style.css` 中实现。
- 数据颜色按 `.s1` 到 `.s4` 的顺序使用。同一份文档中，同一类数据始终使用同一种颜色。
- 代码块添加 `translate="no"`，检查脚本不按中文规则检查其中的代码。
- 品牌、产品等专有名词放在 `<span translate="no">` 中。
