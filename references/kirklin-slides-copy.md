# 文字规范

## 适用范围

本规范适用于配图上的全部文字，包括眉标题、标题、正文、卡片、图表标签和页脚，以及配图在文档中的位置和图片说明。所有风格使用同一份文字规范。

## 通用规则

- 中文与英文、数字之间加一个空格，例如 `共 12 个模块`、`约 70%`、`API 文档`。
- 日期写作 `3月15日`、`2026年1月`，数字与年、月、日之间不加空格。
- 汉字之间不加空格。
- 中文语句使用全角标点：，。、；：？！「」（）。英文和数字内部的符号使用半角，例如 `2.5`、`1,280`、`70%`。
- 全角标点前后不加空格。
- 数值范围用「到」连接，例如 `20 到 30 人天`。
- 四位以上的数字使用千位分隔符，例如 `1,280`；一万以上的数字使用「万」，例如 `3.6 万行`。
- 用于比较或统计的数字、带单位的数量和十以上的数使用阿拉伯数字，例如 `12 个页面`、`3 到 4 周`。十以内且在句中顺带提及的数量使用汉字，例如 `三个模块`、`两种做法`。
- 引用的名称使用直角引号，例如「年度报告」。
- 不使用感叹号和表情符号。
- 品牌、产品等专有名词保持原有写法，并放在 `<span translate="no">` 中，检查脚本不检查其中的空格和标点。

## 数据来源

配图中的数字、人名和日期来自用户提供的材料，或由材料直接计算得出，例如累加的总周数、按先后顺序排出的起止周、多个数值中的最大值。计算得出的数字需要在页脚注明计算方法。材料中没有且无法计算的数字不写入配图，也不做估算。

比例尺、坐标等绘图用的数字不属于数据，可根据版面需要确定。

## 眉标题

眉标题标明当前页所属的部分，例如 `时间安排`、`现状`、`两种做法`。眉标题长度为 2 到 10 个字，不带标点。同一部分的各页使用相同的眉标题。

## 标题

标题为一个完整的句子，内容是当前页的结论，以句号结尾。结论包含关键数字时，将数字写入标题。

标题最多两行，第二行通过 `<br>` 在语义完整处换行，每行字数的上限参见所选风格的规范。页面右侧有大数字或图表时，标题在左半边换行。

封面的项目名、章节页的名称和结束语属于名称，不加句号。

标题的写法示例如下：

| 推荐 | 避免 |
|-|-|
| `新流程让审批少等两天。` | `审批流程介绍` |
| `退款率降到 1.2%。` | `退款率有所下降。` |
| `下个季度先做三件事。` | `下一步计划如下` |

## 正文

正文用一到两句话补充标题，说明原因、范围或做法，最多三行，以句号结尾。正文需要写明负责人、事项和数量，例如 `每个模块由 2 到 3 人负责`。需要强调的句子使用 `<b>`，每页最多一处。

## 卡片、方块和图表

- 卡片标题为短语，不带标点，例如 `数据不用迁移`。
- 卡片说明为一个句子，不加句号，最多两行。
- 方块标签的长度为 2 到 10 个字，用于说明数字的含义，例如 `外部对接`。
- 大数字只包含数字，单位和量词使用小一号的字（`<small>`），例如 `32` 加 `个`。
- 图例、刻度和坐标轴名称为短语，不带标点。
- 同一个数字在不同页中的写法保持一致。

## 用词

配图使用具体、通用的说法。常见的替换如下表：

| 推荐 | 避免 | 说明 |
|-|-|-|
| 付款失败 | 异常 | 写明具体情况 |
| 登录失败 | 鉴权异常 | 使用读者熟悉的说法 |
| 自动化测试 | 单测 | 使用全称 |
| 使用的技术 | 技术栈 | 写明具体的技术 |
| 实施、上线 | 落地 | |
| 确定 | 钉死 | |
| 统一、一致 | 对齐 | |
| 完整的流程 | 闭环 | |
| 连通 | 打通 | |
| 细节 | 颗粒度 | |
| 支持、帮助 | 赋能 | |
| 办法 | 抓手 | |
| 根本原因 | 底层逻辑 | |

配图中不使用「不是……而是……」句式。人名、团队名和系统名与用户材料保持一致。

## 页脚

页脚用于注明资料来源或计算方法，例如 `资料来源：来源名称`、`人天按工作日乘以人数计算`。页脚不加句号，多项内容之间用分号分隔。使用比例尺的图表需要在页脚注明比例尺。

## 文档中的配图

配图放在描述同一内容的段落之后。小节只描述这一内容时，配图放在小节标题下方。

图片说明是 Markdown 中 `![说明](路径)` 的说明部分，读者不看图片也能通过说明了解图片内容。导出全部配图时，图片说明同时用作文件名。

图片说明通常使用当前页的标题，并去掉句末的句号，例如 `![新流程让审批少等两天](slides/out/05-process.png)`。标题以数字开头、无法体现内容时，使用眉标题作为说明，例如标题为 `120 万元。` 的页面，图片说明为 `年度投入`。标题修改后，文档中的图片说明需要同步修改。

## 检查清单

- 检查脚本未报告问题。
- 数字、人名和日期均能在用户材料中找到，或能由材料计算得出。
- 每页标题均为结论句，以句号结尾。
- 同一概念在全部配图中使用同一个词。
